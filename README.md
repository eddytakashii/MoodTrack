# MoodTrack

Projeto
Um MVP completo que demonstra integração full-stack moderna, combinando backend escalável em Node.js com TypeScript, aplicativo mobile em React Native e simulação de dispositivos IoT.

Tecnologias usadas
Backend: Node.js + TypeScript + Express
Mobile: React Native + Expo
Banco: SQLite com TypeORM
Segurança: JWT + bcrypt
Testes: Jest + Supertest
IoT: Simulação com eventos

Objetivo
O sistema permite registro e análise de estados emocionais com autenticação segura, persistência local e sincronização em tempo real.

Funcionalidades
Camada de apresentação -> Interface mobile em React Native com navegação fluida e componentes reutilizáveis
API REST -> Backend Node.js com endpoints seguros, validação de dados e tratamento de erros
Camada de Dados -> SQLite com TypeORM para persistência, relacionamentos e migrações automáticas
Integração IoT

Meu papel
Fui responsavel pela integração com API e integração front-end usando node.js
